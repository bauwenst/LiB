# LiBTok
Refactor of the Less-is-Better vocabulariser/tokeniser.

---

This repository archives the code and data in paper `Less is Better: A cognitively inspired unsupervised model for language segmentation`
(https://aclanthology.org/2020.cogalex-1.4/).

> Yang, J., Frank, S. L., & van den Bosch, A. (2020). Less is Better: A cognitively inspired unsupervised model for language segmentation. Proceedings of the Workshop on the Cognitive Aspects of the Lexicon, 33–45.

The online demo of LiB is here:
https://hub.gke2.mybinder.org/user/ray306-lib_demo-2aracalt/doc/workspaces/auto-8/tree/Quick_Demo.ipynb
You can run the `demo.ipynb` Jupyter notebook to see the segmentation result.

--- 

The code and data of the follow-up paper `Unsupervised text segmentation predicts eye fixations during reading` are archived in https://github.com/ray306/LiB-predicts-eye-fixations/
